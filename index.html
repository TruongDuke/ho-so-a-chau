Hồ sơ cước vận chuyển — HTX Á Châu

Kéo PDF hợp đồng (và hoá đơn) vào, kiểm số, bấm nút để tải file Word đúng mẫu. File chỉ đọc trên máy này, không gửi đi đâu.

1 Hợp đồng

Kéo hợp đồng (PDF hoặc Word) vào đây hoặc bấm để chọn file

2 Hoá đơn (khi làm đề nghị thanh toán + quyết toán)

Kéo PDF hoá đơn vào đây hoặc bấm để chọn file

3 Đã tạm ứng / đã thanh toán

4 Tải file Word

Đề nghị tạm ứng

Cần hợp đồng.

Đề nghị thanh toán

Cần hợp đồng + hoá đơn.

Biên bản quyết toán

Cần hợp đồng + hoá đơn.

PDF có dấu: bấm nút → hiện hộp In → ở ô Máy in / Đích chọn "Lưu dưới dạng PDF" (Save as PDF) → Lưu. Chrome nhớ lựa chọn này cho lần sau. Bản "Word không dấu" để in ra ký, đóng dấu thật.
